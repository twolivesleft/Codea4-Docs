:reference-section: Sharing & Storage

Accessing projects in Files
===========================

Use the Files app to find, back up, and share your Codea projects.

Find local projects
-------------------

In **Files**, open **Browse** and choose **On My iPad > Codea** or **On My iPhone > Codea**. Collections appear as folders, and projects have the ``.codea`` extension, which Files may hide.

Find iCloud projects
--------------------

Choose **iCloud Drive > Codea**. If it is missing, check that iCloud Drive is enabled and Codea has access to it. Projects may need to download before opening.

Work with project documents
---------------------------

Touch and hold a project for actions such as **Copy**, **Move**, **Rename**, **Share**, or **Compress**. Keep the whole ``.codea`` package together so its code and assets travel with it. Tap a project to open it in Codea; opening external projects can require Codea Pro.

You can also move projects using **Move to Device** and **Move to iCloud** in Codea. Changes made in Files affect the projects you see in Codea.

See `Apple's Files guide <https://support.apple.com/guide/ipad/ipad4aaf0d7f/ipados>`_ for the current location sidebar and file-management controls.
