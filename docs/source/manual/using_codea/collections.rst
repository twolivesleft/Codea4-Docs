:reference-section: Project Browser

Organizing project collections
==============================

A collection is a named group of projects. Use collections for lessons, game ideas, reusable libraries, or finished work. Each collection has a Local or iCloud location, shown beside its name in the sidebar.

Create a collection
-------------------

.. codea-media:: images/using_codea/sidebar.png
   :type: image
   :alt: The collections sidebar showing Reference, Assets, Shader Lab, and the Examples collection
   :caption: Open the sidebar to find tools and collections. Collection rows show their storage location and project count.

1. Open the left sidebar and find **Collections**.
2. Choose **New Collection**.
3. Enter a **Collection Name** and choose **Collection Location**: Local or iCloud.
4. Finish editing the name with the keyboard's Done/Return action to create it.

Choose a distinct name in that location. Creating custom collections is a Codea Pro feature.

Reorder collections
-------------------

Drag the handle beside a collection in the left sidebar to change its position in the project browser.

Expand and collapse the grid
----------------------------

Tap a collection’s header in the grid to show or hide its projects.

Move projects between collections
---------------------------------

Touch and hold a project, then drag it to another collection in the grid. If the destination has both Local and iCloud storage, Codea asks which location to use.

Projects within a collection follow the **Recent** or **Name** sorting choice in **Settings > Projects**. Dragging within the same collection is not a manual project-ordering feature.

Deleting a collection also deletes the projects it contains.
