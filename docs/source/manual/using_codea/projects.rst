:reference-section: Project Browser

Creating and customizing projects
=================================

Create a project when you want a fresh starting point; duplicate one when you want to keep its code and assets as a starting point for another idea.

Create a project
----------------

1. Tap the add-project tile in the project browser.
2. Enter a name that you will recognize in the grid.
3. Choose a **Project Template**. Use a modern template for the Carbide API documented in this reference; existing legacy projects can continue to use the legacy renderer.
4. Choose the destination collection and its Local or iCloud location where offered.
5. Choose a tint if desired, then confirm the form to create the project and open its editor.

Duplicate a project
-------------------

Touch and hold the original and choose **Duplicate**. In the form, choose the new name and destination, then confirm. Work on the copy when you want to preserve the original, especially before experimenting with a built-in example.

Rename a project
----------------

Touch and hold one of your projects and choose **Rename**. Change its name and confirm the form. Built-in collections do not expose Rename; duplicate their projects into your own collection first.

Set a custom tint
-----------------

The project form includes a **Tint** color picker next to the icon. Set it while creating or duplicating a project. For an existing project, open **Rename**, leave the name unchanged if you wish, and adjust its tint before confirming.

The tint controls the project's generated icon appearance; it does not change colors drawn by your Lua code. Use **Clear Tint** in the color control to return to the automatic appearance. The icon preview lets you see the result before saving.
