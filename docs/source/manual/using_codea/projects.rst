:reference-section: Project Browser

Creating and customizing projects
=================================

Start a new project or duplicate one to build on an existing idea.

Create a project
----------------

1. Tap the add-project tile in the project browser.
2. Enter a name that you will recognize in the grid.
3. Choose a **Project Template**. Choose **Modern** to follow this reference, or **Legacy** to work with older Codea code.
4. Choose the destination collection and its Local or iCloud location where offered.
5. Choose a tint if desired, then confirm the form to create the project and open its editor.

Duplicate a project
-------------------

Touch and hold a project and choose **Duplicate**. Choose a name and destination for the copy. Duplicate built-in examples before experimenting if you want to keep the originals.

Rename a project
----------------

Touch and hold a project and choose **Rename**. Enter a new name and confirm. To rename a built-in example, duplicate it into your own collection first.

Set a custom tint
-----------------

The project form includes a **Tint** color picker next to the icon. Set it while creating or duplicating a project. For an existing project, open **Rename**, leave the name unchanged if you wish, and adjust its tint before confirming.

The tint changes the project icon. Use **Clear Tint** to restore its automatic color, and check the preview before saving.
