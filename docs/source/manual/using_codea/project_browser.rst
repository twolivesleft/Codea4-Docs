:reference-section: Project Browser

The project browser
===================

The project browser is Codea's home screen: open a project to edit it, run one to try it, or organize your work into collections. A project contains its Lua code, settings, and any assets stored with it.

Find your way around
--------------------

.. codea-media:: images/using_codea/project-browser.png
   :type: image
   :alt: The project grid showing the Examples collection, project filter, and browser controls
   :caption: Browse projects in a collection. Control placement adapts to your device and window size.

* **Project grid:** tap a project to open its editor. Touch and hold a project for actions such as **Play**, **Duplicate**, and **Export**. With a mouse or trackpad, use the secondary click.
* **New project:** use the add-project tile in the grid. The creation form lets you choose a name, template, destination, and tint.
* **Left sidebar:** open the tools/collections sidebar to browse **Reference**, **Assets**, **Shader Lab**, and your collections.
* **Settings and Air Code:** use the gear to open Settings and the Air Code control to open its connection menu. Air Code is also available within Settings.

Start with an example
---------------------

Open an example to read its code, or choose **Play** from its menu to run it. To experiment without changing the supplied version, choose **Duplicate**, give the copy a useful name, and save it in your own collection. Built-in examples do not offer all of the same actions as your own projects.

Try duplicating a drawing example, changing a color, and running it again. See **How Codea Works** in the **Lua** chapter to learn about ``setup()``, ``draw()``, and responding to input.

Finding and organizing work
---------------------------

Use **Filter projects** to find a project by name. Keep related projects in collections and collapse the ones you are not using. Choose **Recent** or **Name** in **Settings > Projects** to sort the grid.

Features marked **Pro** require Codea Pro.
