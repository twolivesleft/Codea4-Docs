:reference-section: Sharing & Storage

Local, iCloud, and collaboration
================================

Local and iCloud describe where a project is stored. They are independent of whether its Lua code uses the modern or legacy renderer.

Choose where to keep a project
------------------------------

**Local** projects live on this device. They remain usable without iCloud and do not automatically appear on your other devices.

**iCloud** projects live in Codea's iCloud Drive storage. iCloud synchronizes them across devices signed in to the same Apple Account. A project may need to download before it can be opened; its menu can offer **Download Now**. Editing iCloud projects in Codea requires Codea Pro.

The project browser can show Local and iCloud projects together. Use the location shown for the collection or the project's cloud indicator to distinguish them, rather than relying on the name alone.

Move between locations
----------------------

Touch and hold a local project and choose **Move to iCloud**, then confirm. For an iCloud project, choose **Move to Device** and confirm. These are moves, not duplicate copies. Duplicate first if you want to keep independent versions in both locations.

Allow a cloud move or download to finish before expecting the project to appear on another device. Moving to the device is also available when an iCloud project cannot be edited with your current Codea entitlement.

Collaborate through iCloud
--------------------------

Keep the project in iCloud Drive. In **Files**, find it under **iCloud Drive > Codea**, touch and hold it, and choose **Share**. Select **Collaborate** rather than sending a copy, choose who can access it and whether they can make changes, then send the invitation.

Participants work with the shared file, whereas sending a copy creates independent versions. Coordinate edits to the same Lua file and allow synchronization to finish when moving between devices. Use the shared item's controls in Files to manage participants or stop sharing. Codea also shows an iCloud collaboration control on available cloud projects.

See `Apple's iCloud sharing guide <https://support.apple.com/guide/ipad/ipade248577c/ipados>`_ for the current invitation and permission controls. Sharing a playable link uploads a playable version instead; it does not grant access to this shared source project.
