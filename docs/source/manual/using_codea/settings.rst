:reference-section: Tools & Settings

Useful settings and backups
===========================

Open Settings from the project browser to adjust the editor, organize projects, and make backups.

Editor
------

.. codea-media:: images/using_codea/settings.png
   :type: image
   :alt: Editor settings with Light, Dark, Auto, font size, editor version, and Editor Preferences
   :caption: The Editor pane brings reading preferences and editor behavior together.

Choose an editor appearance and font size. Open **Editor Preferences** for line wrapping, formatting on paste, scrolling, autocomplete, and Code Notes. Use **Editor Version**, where available, to choose the editing interface.

Projects
--------

Sort projects by **Recent** or **Name**, and choose **Small** or **Large** project icons.

**Restore All Examples** replaces the built-in examples with their original versions. Duplicate any edited examples into your own collection first to keep your changes.

**Export All Projects** creates **CodeaProjects.zip** for you to save or share. It includes local projects, excluding built-in examples and some support files. Back up iCloud projects separately through Files or by exporting them.

Air Code
--------

Enable the remote connection, copy the server address, or open the setup guides for VS Code, the CLI, and MCP clients. See the Air Code page in this chapter for the connection workflow.

Windowing
---------

Choose **Single Window** to open and run projects in the current window, or **New Window** to use separate windows on supported devices.

Subscription controls
---------------------

Use **Manage Subscription** to manage Codea Pro.
