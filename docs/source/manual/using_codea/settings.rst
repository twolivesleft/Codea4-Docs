Useful settings and backups
===========================

Open Settings from the project browser. These panes change how you work; appearance-only options such as the app icon and background artwork are not required to follow this guide.

Editor
------

.. codea-media:: images/using_codea/settings.png
   :type: image
   :alt: Editor settings with Light, Dark, Auto, font size, editor version, and Editor Preferences
   :caption: The Editor pane brings reading preferences and editor behavior together.

Choose the editor appearance and font size for comfortable reading. **Editor Preferences** includes line wrapping, formatting on paste, scrolling, autocomplete behavior, and Code Notes options. Where an editor-version selector is available, it changes the editing interface, not the renderer used by an existing project.

Projects
--------

**Sort projects by** offers **Recent** and **Name**. **Project icon size** offers **Small** and **Large**. These change the grid presentation without moving projects between collections.

**Restore All Examples** replaces the supplied example projects with their default versions. The confirmation warns that edits to those built-in examples will be deleted. Duplicate an edited example into your own collection before restoring if you want to keep your changes.

**Export All Projects** creates **CodeaProjects.zip** and opens the export/share flow so you can save it elsewhere. In the current implementation, this archives the device's local Documents storage and excludes built-in example folders and some support files. It is not a complete backup of iCloud Drive; separately preserve cloud projects through Files or export the projects you need.

Air Code
--------

Enable the remote connection, copy the server address, or open the setup guides for VS Code, the CLI, and MCP clients. See the Air Code page in this chapter for the connection workflow.

Windowing
---------

Choose **Single Window** to open and run projects within the current window, or **New Window** to use separate windows where the device and current environment support them. This controls how Codea presents projects; it does not create extra copies of their files.

Subscription controls
---------------------

Use **Manage Subscription** when you need to manage Codea Pro. Features with a Pro badge can open the subscription screen instead of proceeding when they are not available with your current entitlement.
