:reference-section: Sharing & Storage

Accessing projects in Files
===========================

Codea exposes its documents to the iOS Files app. Use Files to find a project document, keep an archive, or access the same iCloud storage outside Codea.

Find local projects
-------------------

Open **Files**, show **Browse** or the locations sidebar, then choose **On My iPad > Codea** or **On My iPhone > Codea**. The device name depends on where you are running Codea. Your collections appear as folders; projects have the .codea extension, which Files may hide.

Find iCloud projects
--------------------

Choose **iCloud Drive > Codea** in Files. This is the cloud location, distinct from the Codea folder under On My iPad/iPhone. If it is unavailable, check that iCloud Drive is enabled for your Apple Account and that Codea has access to it. Cloud-only items may need to download before opening.

Work with project documents
---------------------------

Touch and hold a project or folder to use Files actions such as Copy, Move, Rename, Share, or Compress. A .codea project is a package containing code and assets; keep the whole package together when transferring or backing up a project. Opening a project from Files hands it to Codea; opening external projects can require Codea Pro.

For a location change that should immediately be reflected in the project browser, Codea's **Move to Device** and **Move to iCloud** commands make the destination explicit. Changes made in Files affect the actual documents, not an exported copy.

See `Apple's Files guide <https://support.apple.com/guide/ipad/ipad4aaf0d7f/ipados>`_ for the current location sidebar and file-management controls.
